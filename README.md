## 🗂️ v9.12 功能模块（共 14 个，按侧边栏三大分区排列）

侧边栏分三区：**置顶常用** → **助手 · 主手脚** → **算力 · 主大脑**。

### 置顶常用

#### 🖥️ 系统总览
实时监控电脑的核心硬件状态。提供 CPU、内存和磁盘的使用情况，并强化了针对 AI 用户的 GPU 监控，直观展示显存占用、核心温度及实时功耗。

#### 📥 速存图文 — 沉浸式素材收集神器
搭配专属浏览器插件，鼠标悬停在图片上按下自定义快捷键（如 `Alt+1`）即可静默保存原图到预设目录；支持全局文本快捷键提取（`F3/F4`），Windows 资源管理器中也能直接生效；`F5~F8` 按顺序自动建文件夹，`F9` 快速建立指定分类目录（如 Grok）。
桌面程序与浏览器插件之间通过本地 WebSocket 长连接通信（插件每 20 秒发一次心跳，35 秒未收到视为断连），页面顶部有三色状态灯（绿=已连接可用 / 黄=等待连接或心跳超时 / 红=不可用）实时提示连接情况。

#### 🎬 视频下载 — 多平台无水印解析 *（v9.10：原「抖音下载」升级为多平台）*
顶部用 Tab 切换 **抖音 / YouTube** 两个平台子页：
- **抖音**：将包含短视频/图文帖链接的任意文本（分享短链、完整网址、大段分享文案均可）粘贴进输入框，自动提取无水印高清视频（MP4）及创作者原声音频；支持导入本地 Cookie 应对复杂网络环境；内置多条解析线路、同线路内部重试、图文帖 HTML 解析、并发下载与文件校验，文件名自动加日期。支持「一键粘贴并解析」：读取剪贴板 → 自动解析 → 直接下载到保存位置。
- **YouTube**：基于 `yt-dlp`，粘贴视频链接即可解析画质并下载；高清音视频合并、转 mp3 依赖本机 `ffmpeg`；解析 JS 挑战需本机 `Deno`（或 Node.js）；未安装 `yt-dlp` 时本页给出安装提示，不阻塞其它页面。

#### 🖼️ 图集下载 *（v9.10 文档补录）*
粘贴漫画/图站网址，解析页面内图片源并批量下载。优先支持 **e-hentai / exhentai** 图库（可导入 Netscape 格式 Cookie 访问 ExHentai），其它站点走通用 HTML 抽图。支持下载间隔、解析后自动下载等选项；内容卡亮=待下/重下，灰=已下（点亮灰卡可强制重下）。

### 助手 · 主手脚

#### 📝 粘贴助手 — 提示词仓库
录入「主题 + 内容」并挑选七色标签，保存为彩色卡片，卡片以流式布局排列、可拖拽调整顺序。单击卡片：复制内容并载入编辑区（可直接修改后更新）；再次点击同一张只复制、不重新刷新表单，避免界面抖动；右键卡片可删除。记录保存在 `records/paste_helper.txt`（JSON Lines）。

#### 💰 积分计算
专为 AI 创作者打造的成本核算工具。输入 Midjourney 等平台的订阅金额、汇率及单次消耗积分，一键折算生成单张图或单秒视频的真实人民币成本，并支持保存历史记录（`records/points_calc.txt`）。

#### ✂️ 截图工具
轻量化且高度自由的截图模块。支持自定义修饰键与主键组合（如 `Ctrl+Alt+A`），截图后自动保存至指定本地目录，支持转换为 PNG/JPG 格式及自动复制到剪贴板，可选截图时自动隐藏主窗口。

#### 📐 比例计算
内置 16:9、21:9 等常用画幅预设，支持快速换算图像宽高像素值；同时集成金额大小写转换及人民币大写汉字速查功能，点击单字即可复制。
> 原来放在本页的「汇率转换器」已于 v9.9 迁移到「时区汇率」页。

#### 📂 目录映射
图形化的系统软链接（目录映射）创建工具，选择源真实路径和目标链接位置即可自动生成并执行 `mklink /D` 映射命令（用 list 形式传参，中文/空格路径安全；可单独勾选「以管理员权限执行」）；附带磁盘空间 Treemap 可视化扫描（盘符横向切换 + 网页 Canvas 渲染的方块图），帮助转移大型应用数据、释放 C 盘空间。Treemap 需 `PyQtWebEngine`，未安装时优雅降级为提示文案。

#### 🌍 时区汇率
左 70% 为多城市中文模拟时钟（可自由增删城市），支持用日历选日期、上下按钮调时分秒来模拟任意时间，并可一键还原为当前实际时间；右 30% 为汇率转换器（以 CNY 为基准，内置参考汇率，可点击「刷新实时汇率」从 `open.er-api.com` 拉取实时数据，失败时自动回退到内置参考值）。

### 算力 · 主大脑

#### ◆ 模型选择 — 全局「主大脑」配置 *（v9.10 文档补录）*
统一切换本页所有 AI 功能所依赖的模型来源，**点哪边用哪边、立即生效、无「保存」按钮**（表单变更防抖自动落盘到 `records/user.txt`）：
- **本地 Ollama**：读取本机已拉取的模型，表格展示名称/参数/量化/体积/上下文，下拉框区分视觉模型（绿）与纯文本模型（红）。
- **云端 OpenAI 兼容 API**：内置 OpenAI、DeepSeek、xAI Grok、通义千问（DashScope）、Moonshot Kimi、智谱 GLM、Mistral、Google Gemini、Groq、OpenRouter（聚合）、硅基流动 SiliconFlow、Together AI 等厂商预设，也可选「自定义 OpenAI 兼容」填任意端点。

> 导演台、Ollama 工具、文学写作等 AI 功能统一通过 `utils/llm_client.py` 读取此处配置，因此它们既能跑本地 Ollama，也能接云端 API。

#### ▷ 导演台
输入故事简介，自动生成 **A 故事简讯与镜头提示词 / B 角色提示词（多角度模型参考）/ C 电影制作板**（≤1000 字，按设定镜头数）三类产出，每类均可单独重新生成并自动保存到 `导演台产出/日期_项目名_序号/` 目录下的对应文本文件。页面本体是一个内嵌的网页（QWebEngineView），通过 QWebChannel 桥接由 Python 转发请求到「主大脑」（规避浏览器端直连的 CORS 限制）；未安装 `PyQtWebEngine` 时会优雅降级为提示文案，不会导致程序崩溃。

#### ◇ Ollama 工具
「反推提示词」与「批量打标」合并为一个页面，通过顶部 Tab 切换：
- **🖼 反推**：本地图片拖拽即可反推提示词，内置 Booru 标签、Midjourney 风格、训练提示词等 9 种全英文输出模式。
- **🏷 打标**：指定图片文件夹 + 输出模板，批量生成对应的 `.txt` 标注文件（支持覆盖），用于训练专属 LoRA 模型。

两者都依赖视觉模型（本地 Ollama 视觉模型，下拉框绿色=视觉、红色=纯文本；亦可走「模型选择」里配置的云端视觉模型）。

#### ✎ 文学写作
本地大模型 · Skill 加载器。左 70% 为回合制对话区（支持附件、斜杠命令 `/clear`/`/reset`/`/new` 清空对话、`/help` 查看命令列表），用户气泡可复制/修改重发，AI 气泡可复制/换种子刷新/删除单个回合；右 30% 为功能区，包含 Skill 目录（勾选后作为系统提示词注入，不勾不生效，目录为项目根的 `skills/`）、运行日志、附件管理。

## 🛠️ 安装与运行

> 建议 **Python 3.10+ / Windows 10+**（手动速存文本、鼠标侧键监听、管理员相关能力需 Windows）

```bash
# 安装依赖
pip install -r requirements.txt

# 运行
python mainv912.py
```

**关于管理员权限**：默认以普通用户启动（减少 UAC 弹窗与杀软误报）。需要时可显式提权：

```bash
python mainv912.py --as-admin
```

目录映射页的 `mklink` 也可单独勾选「以管理员权限执行」，不必整程序提权。

**可选环境**
- **NVIDIA**：用于 GPU 监控，需 `nvidia-smi` 在 PATH 中；否则 GPU/显存/温度/功耗显示 0。
- **本地 Ollama**：用于反推提示词、批量打标、导演台、文学写作（也可在「模型选择」改用云端 API）。视觉模型需手动拉取，例如：
  ```bash
  ollama pull llava:latest
  ollama pull qwen2-vl:7b
  ```
- **PyQtWebEngine**（含 QtWebChannel）：导演台、目录映射的磁盘 Treemap 需要，未安装时对应功能会降级为提示文案。
- **yt-dlp + ffmpeg + Deno/Node.js**：视频下载页的 YouTube 子页需要，未安装时该子页给出提示，不影响其它页面。
- **浏览器扩展（MV4）**：配合速存图文使用，通过本地 WebSocket 与桌面程序保持心跳连接，支持 Pixiv 等防盗链站点。

> ℹ️ 本次 zip 包中未包含 `MV4/` 浏览器扩展目录，请确认是否随包一同分发。`skills/` 目录已随包附带（当前为空，可自行放入技能文件供文学写作页勾选注入）。

### 🧩 附：浏览器扩展（MV4）安装步骤（速存图文，必装）

1. **打开扩展管理页面**：Chrome 地址栏输入 `chrome://extensions/`（或右上角「三点」→「扩展程序」→「管理扩展程序」）。
2. **开启开发者模式**：扩展程序页面右上角打开「开发者模式」开关。
3. **加载插件文件夹**：点击左上角「加载已解压的扩展程序」。
4. **选择项目目录**：选择本地 `MV4` 文件夹即可完成安装。

## ❗ 常见问题

- **`ModuleNotFoundError: No module named 'utils'`**
  → 确认从项目根目录运行 `python mainv912.py`，不要在子目录里启动。

- **资源监控无 GPU 数据**
  → 安装 `psutil`；若无 NVIDIA 或 `nvidia-smi` 不在 PATH，GPU/显存/温度/功耗显示 0，不影响其他功能。

- **反推提示词返回空 / 图片未发送**
  → 确认所选模型是视觉模型（本地下拉绿色=视觉，红色=纯文本）；若模型名不被识别，勾选「强制发送图片」复选框。

- **批量打标无输出**
  → 确认 Ollama 已启动且已拉取视觉模型；或在「模型选择」页配置可用的云端视觉模型；点击「刷新」重新获取模型列表。

- **导演台 / 文学写作 无法生成**
  → 导演台页面空白多为未安装 `PyQtWebEngine`；生成失败请到「模型选择」确认主大脑可用（本地 Ollama 在 `http://localhost:11434` 运行，或云端 API Key 已填）。

- **YouTube 无法解析 / 下载**
  → 需安装 `yt-dlp`；高清合并 / 转 mp3 需本机 `ffmpeg`；解析 JS 挑战需 `Deno`（或 Node.js）在 PATH 中。

- **图集下载访问 ExHentai 失败**
  → 需导入有效的 Netscape 格式 Cookie（可用浏览器扩展「Get cookies.txt LOCALLY」导出）。

- **时区汇率刷新实时汇率失败**
  → 依赖 `open.er-api.com` 网络请求，失败时会自动回退使用内置参考汇率，不影响手动编辑换算。

- **手动速存文本（F7）不响应**
  → 依赖 `pywin32`（仅 Windows）；确认已在「速存图文」页面开启「速存图片」开关，F7 随之生效。

- **速存图片插件状态灯一直是黄色/红色**
  → 黄色多为「等待插件连接」或「心跳超时」，确认 Chrome 已打开且插件已加载；红色多为端口被占用或 Chrome 未运行；确认程序以**管理员权限**运行，或在安全软件白名单中放行。

## ✅ 开发规范

- **样式与逻辑分离**：所有视觉样式写入 `assets/app.qss` / `app_light.qss` 与 `styles/style_all.py`；布局、定时刷新、业务逻辑写在 Python。
- **样式钩子**：用 `setObjectName()`、`setProperty("titleVariant","accent")`、`setProperty("typo","...")` 精准命中 QSS，避免 `setStyleSheet()` 内联污染。
- **优雅降级**：`psutil` / `nvidia-smi` / Ollama / `PyQtWebEngine` / `yt-dlp` 不可用时提示但不崩溃。
- **Windows 依赖隔离**：`pywin32`、`ctypes` WinAPI 相关代码均有 `try/except` 保护。
- **后台线程与关窗清理**：子页面挂在 `QStackedWidget` 里不会单独触发 `closeEvent`，涉及定时器/后台线程/`QThread` worker 的页面需在主窗口关闭时统一停止（见 `ui_main.py` 的 `closeEvent`），避免「窗口已关、线程还在跑」的报错。
- **持久化原子写入**：用户配置采用「写 `.tmp` + `os.replace`」原子落盘（见 `utils/user_prefs.py`），避免写入中断损坏文件。
