## ✨ 这货能干嘛

### 🖼️ 速存图文（剪贴板保姆）
- 开关一按就上岗：监听剪贴板里的**图片**，自动存成 PNG。  
- 下一次复制的**文本**会自动配对成**同名 .txt**（图文成双不走散）。  
- 内置**去重**（SHA1 指纹），防止手抖存一墙。  
- 自定义保存路径，有列表可翻账。  
- 可选启动一个**本地小服务**（127.0.0.1:8787）给外部工具塞东西进来——真·接力干活。

---

### ✂️ 截图工具（热键 + 区域框选）
- **组合键自选**：支持 `Ctrl/Alt/Shift` + `F1~F12 / A~Z / 0~9 / Space / Insert`。  
  > 笔记本党福音：`Ctrl+Shift+A` 一把梭，告别 Fn 键体操。  
- **左键拖拽**框选，**右键**取消，**Esc** 退出。  
- 自动保存为 PNG；保存列表**固定 400px** 高度，清清楚楚。  
- 切换到其它页面时**自动停用监听**，不抢键、不捣乱。  
- 状态栏随时报告：未启用 / 等待热键 / 已完成 / 取消。

---

### 📐 比例计算器（A:B = C:D）
- 实时计算 `D = B × C ÷ A`（600ms 防抖，打字不卡）。  
- **交换** A/B 一键对调；**复制** D 的**整数部分**到剪贴板。  
- 输入框居中大字，盯一眼就会算。

## 🧠 小贴士（你可能会问）
- **热键没反应？** 试着用管理员运行；或换个组合（比如 `Ctrl+Shift+A`）。  
- **最后一行看不全？** 已加“尾部垫片”+ 像素滚动；手动滚到最底也稳稳能看到。  
- **图片/文本保存在哪里？** 各自页面里都能改路径；默认图文在 `~/Pictures/WebImageSaver`，截图在你设定的 `ScreenshotImageSaver`（你可以保持这个个人习惯）。  
- **Ollama 不在？** 页面会提示“未检测到”，其它功能不受影响。
