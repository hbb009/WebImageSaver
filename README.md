## 🆕 v9.8 核心功能模块

### 📥 **速存图文— 沉浸式素材收集神器**
- 在这个信息碎片化的时代，每天在网页浏览中遇到有价值的图片或文字时，传统的“右键-另存为-选择路径”操作不仅繁琐，更会打断你的工作心流。为此，我们特别开发了“速存图文”功能，这是一款真正的效率神器。
- 通过搭配专属的浏览器插件，你只需将鼠标悬停在心仪的图片上，按下自定义快捷键（例如 `Alt+1`），原图就会瞬间静默保存到你预设的本地目录中，全程无弹窗打扰。不仅如此，它还支持全局文本快捷键提取（`F3/F4`），即使在 Windows 资源管理器中操作也能直接生效。针对需要高频整理素材的用户，我们加入了“速建文件夹”功能，按下 `F5` 至 `F8` 即可按顺序自动创建文件夹，或使用 `F9` 快速建立特定名称（如 Grok）的分类目录。所有保存路径与日志一目了然，让你专注于内容本身，极大提升资料收集效率。

### 🧮 **抖音下载 — 纯净无水印的解析利器**
- 无论你是短视频创作者需要收集优质素材，还是普通用户想要保存喜欢的视频，寻找一款纯净、高效的无水印下载工具总是令人头疼。“抖音下载”模块正是为你解决这一痛点而生，它具备极其强大的智能解析能力。
- 你只需将包含短视频链接的任意文本（不管是分享短链、完整网址，还是大段带有链接的分享文案）直接粘贴进输入框，系统便会自动提取出无水印的高清视频（MP4格式）以及创作者的原声音频。为了保证解析的稳定性和高成功率，系统支持导入本地 Cookie 配置文件，有效应对复杂网络环境与防抓取限制。解析完成后，媒体文件会以卡片形式直观展示，支持一键“全选”或自由勾选，点击“开始下载”即可极速保存至本地。底部的运行日志能随时监控请求状态，是自媒体人不可或缺的实用利器。

### 🖥️ **系统总览**
- 实时监控电脑的核心硬件状态。不仅提供 CPU、内存和磁盘的使用情况，还特别强化了针对 AI 用户的 GPU 监控，直观展示显存占用、核心温度及实时功耗，助你精准掌握电脑运行健康度。
### 💰 **积分计算**
- 专为 AI 创作者打造的成本核算工具。输入 Midjourney 等平台的订阅金额、汇率及单次消耗积分，即可一键折算生成单张图或单秒视频的真实人民币成本，并支持保存历史记录，花销一目了然。
### ✂️ **截图工具**
- 轻量化且高度自由的截图模块。支持自定义修饰键与主键组合（如 `Ctrl+Alt+A`），截取屏幕后可自动隐式保存至指定本地目录，支持转换为 PNG/JPG 格式及自动复制到剪贴板，满足日常快速截图需求。
### 📐 比例计算
- 内置 16:9、21:9 等 8 种常用画幅预设，支持快速换算图像宽高像素值，是绘图和排版的好帮手。同时集成金额大小写转换及人民币大写汉字速查功能，点击单字即可复制，财务办公更便捷。
### 📂 目录映射
- 图形化的系统软链接（目录映射）创建工具。只需选择源真实路径和目标链接位置，即可自动生成并执行映射命令。附带磁盘空间扫描功能，帮助你轻松转移大型应用数据，释放 C 盘空间。
### 🌍 时区汇率
- 出海业务与跨国交流必备的效率小组件。提供全球主要时区的实时时间对照，以及常用的多币种实时汇率换算。界面直观操作极简，告别频繁打开网页查询的烦恼。

## 🤖 本地 AI 算力工具 (需部署大模型)
### 1. StableDiffusion Mini
一键接管并启动本地 Stable Diffusion 环境。支持直接复用现有的 A1111 或 ComfyUI 内置 Python 环境（免重装 torch 与 CUDA），自动检测依赖，让本地 AI 绘画服务的启动与管理极简高效。

### 2. ComfyUI Mini
专为 ComfyUI 打造的轻量级启动控制器。精准配置工作流目录与解释器路径，支持后台启动、进程释放及 API 连通性检测。可有效避免手动开启引起的进度条写入错误，保障本地节点运行的绝对稳定。

### 3. 视觉反推 (基于 Ollama)
无缝接入本地 Ollama 视觉大模型，实现单图拖拽极速反推。内置 Booru 标签、Midjourney 风格、训练提示词等 9 种专业的全英文 Prompt 输出模式，精准解析图像特征，完美赋能本地图像生成。

### 4. 批量打标 (基于 Ollama)
本地图库整理与模型训练利器。搭配 Ollama 视觉模型实现全自动批量图像打标，只需指定文件夹并选择输出模板，即可快速生成对应的 `.txt` 标注文件（支持覆盖），是训练专属 LoRA 模型的绝佳辅助。

### 5. 本地对话 (基于 Ollama)
直连本地部署的 Ollama 语言大模型，提供纯净无打扰的交互界面。支持一键开启联网搜索与深度思考模式，所有对话数据完全留存本地，在保障绝对隐私的同时，随时调用强大的 AI 逻辑推理算力。

## 🛠️ 安装与运行

> 建议 **Python 3.10+ / Windows 10+**（手动速存文本需 Windows）

```bash
# 安装依赖
pip install -r requirements.txt

# 运行
python mainv98.py
```

**可选环境**
- **NVIDIA**：用于 GPU 监控，需 `nvidia-smi` 在 PATH 中；否则 GPU/显存/温度/功耗显示 0。
- **Ollama**：用于反推提示词和批量打标；视觉模型需手动拉取，例如：
  ```bash
  ollama pull llava:latest
  ollama pull qwen2-vl:7b
  ```
- **浏览器扩展（MV3）**：配合速存图文使用，安装 `MV3/` 目录下的扩展可增强图片保存兼容性（可选）。

### 🧩 附：浏览器扩展（MV3）安装步骤（速存图文，必装）

如果需要使用“速存图文”功能并增强网页图片的保存兼容性，请手动将配套的浏览器插件安装到 Google Chrome 中：

1. **打开扩展管理页面**：打开 Chrome 浏览器，在地址栏输入 `chrome://extensions/` 并回车（或点击浏览器右上角“三点”图标 -> “扩展程序” -> “管理扩展程序”）。
    
2. **开启开发者模式**：在扩展程序页面右上角，找到并打开 **“开发者模式”** 开关。
    
3. **加载插件文件夹**：点击页面左上角出现的 **“加载已解压的扩展程序”** 按钮。
    
4. **选择项目目录**：在弹出的文件选择框中，找到你本地的 **`MV3` 文件夹**，点击“选择文件夹”即可完成安装。

## ❗ 常见问题

- **`ModuleNotFoundError: No module named 'utils'`**
  → 确认从项目根目录运行 `python mainv98.py`，不要在子目录里启动。

- **资源监控无 GPU 数据**
  → 安装 `psutil`；若无 NVIDIA 或 `nvidia-smi` 不在 PATH，GPU/显存/温度/功耗显示 0，不影响其他功能。

- **反推提示词返回空 / 图片未发送**
  → 确认选择的模型是视觉模型（下拉绿色=视觉，红色=纯文本）；若模型名不被识别，勾选"强制发送图片"复选框。

- **批量打标无输出**
  → 确认 Ollama 已启动且已拉取视觉模型；点击"刷新"按钮重新获取模型列表。

- **手动速存文本（F7）不响应**
  → 依赖 `pywin32`（仅 Windows）；确认已在"速存图文"页面开启"速存图片"开关，F7 随之生效。

- **速存图片侧键无反应**
  → 鼠标侧键监听依赖 Windows 全局钩子；确认程序以**管理员权限**运行，或在安全软件白名单中放行。

## ✅ 开发规范

- **样式与逻辑分离**：所有视觉样式写入 `assets/app.qss`；布局、定时刷新、业务逻辑写在 Python。
- **样式钩子**：用 `setObjectName()`、`setProperty("titleVariant","accent")`、`setProperty("typo","...")` 精准命中 QSS，避免 `setStyleSheet()` 内联污染。
- **优雅降级**：`psutil` / `nvidia-smi` / Ollama 不可用时提示但不崩溃。
- **Windows 依赖隔离**：`pywin32`、`ctypes` WinAPI 相关代码均有 `try/except` 保护。
