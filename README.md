## 🆕 v8.1 有什么新变化

### 🖼️ 速存图文：新增「自动」与「手动」两种模式（互斥，二选一）
- **顶部两块分组**：左侧“图文自动保存”、右侧“图文手动保存”，均为系统原生 `QGroupBox` 样式（标题“切开”白色外框）。
- **模式互斥**：开“自动”会强制关“手动”；开“手动”会强制关“自动”；**离开本页**两种模式都会被关闭。
- **共享区域（蓝色）**：两种模式**共用**同一“图文保存路径”和“内容列表日志”。

#### 自动模式
- 监听剪贴板里的**图片**，自动保存为 PNG。
- 下一次复制的**文本**会自动配对成**同名 .txt**（图文配对不走散）。
- 内置**去重**（SHA1 指纹），防止重复保存。
- 提示：使用 **Google Chrome** 时，可安装项目内 `chrome_image_saver_configurable` 扩展，按 **Alt + 鼠标左键** 在网页上**快速保存图片**。

#### 手动模式（Windows）
- 在**资源管理器**中选中文件 → 按页面内选定的快捷键（默认 **F7**）→ 在**同目录创建同名 `.txt`** 并写入**剪贴板文本**。
- 快捷键可在下拉框中选择 **F5 / F6 / F7 / F8**（仅在“手动模式”启用时生效）。
- 依赖：`pywin32`、`pyperclip`（仅 Windows）。

### 📁 保存路径的“自愈”与兼容老系统
- 首次启动或路径无效时，程序会**自动寻找可写目录**并创建：
  1) `图片库\WebImageSaver`（系统“图片”文件夹）
  2) `%USERPROFILE%\WebImageSaver`
  3) 程序当前目录 `.\WebImageSaver`
- 若以上都不可写，会**弹出目录选择对话框**，直到选到可写目录为止。
- 当路径不可写时，**禁止启用自动/手动模式**并在日志中提示。
- 这样即便对方电脑**没有** `C:\Users\xxx\Pictures\WebImageSaver` 也能正常使用。

## ✨ 其它功能一览

### ✂️ 截图工具（热键 + 区域框选）
- 组合键可配（如 `Ctrl/Alt/Shift + F1~F12/A~Z/0~9/Space`）。
- 左键拖拽框选，右键取消，`Esc` 退出。自动保存为 PNG。
- 切换到其它页面时**自动停用监听**，不抢键、不干扰。

### 📐 比例计算器（A:B = C:D）
- 实时计算 `D = B × C ÷ A`（含防抖）。
- **交换** A/B 一键对调；**复制** D 的**整数部分**到剪贴板。

### 🤖 Ollama 助理（本地模型聊天）
- 自动检测 Ollama；下拉选择模型；流式输出；一键清空对话。
